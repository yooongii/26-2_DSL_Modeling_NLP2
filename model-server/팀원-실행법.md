# 리뷰 탭 돌려보기 (팀원용)

아고다 숙소 페이지에서 리뷰를 자동 수집·분석해 "화면 밖에서 낼 수 있는 추가비용"을
보여준다. **콘솔에 한 줄 붙여넣으면 끝난다.**

---

## 필요한 것은 두 가지뿐

| | 어디서 | 왜 |
|---|---|---|
| **모델 폴더** `ckpt/` (한국어·영어 2개) | 구글 드라이브 | 학습 결과(합쳐서 약 520MB). GitHub 100MB 제한을 넘어 못 올린다 |
| **이 저장소** | git pull | 실행 코드 |

브라우저 번들(`review-panel.console.js`)은 **따로 받을 필요 없다.** 서버가 직접 내려준다.

---

## 1. 모델 받기

드라이브의 `ckpt_v3` 를 받아 **폴더 이름 그대로** 아래에 넣는다. 한국어·영어 두 개다.

```
model-server/ckpt/
├── klue_roberta-small/          ← 한국어 (261MB · 이진)
│   ├── config.json
│   ├── model.safetensors
│   ├── tokenizer.json
│   └── tokenizer_config.json
└── distilbert-base-uncased/     ← 영어 (257MB · 이진)
    └── (같은 구성)
```

> 폴더 이름이 곧 모델 이름이다 — `serve.py` 가 `--model klue/roberta-small` 의 `/` 를 `_` 로
> 바꿔 폴더를 찾는다. 이름을 바꾸면 못 찾는다.

> `ckpt/` 는 `.gitignore` 에 걸려 있어 git 에 안 올라간다. **드라이브가 유일한 원본이다.**
> (배포본은 Cloud Run 이미지 안에도 구워져 있다.)

현재 두 모델 다 **이진**이라 `thresholds.json` 이 없다. 유형(types)은 서버가 아니라
클라이언트 규칙 층이 붙인다.

## 2. 파이썬 환경 (최초 1회)

```bash
cd model-server
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe torch --index-url https://download.pytorch.org/whl/cu128
uv pip install --python .venv/Scripts/python.exe transformers pandas numpy scikit-learn accelerate "datasets<4"
```

- `uv` 가 없으면: `pip install uv` 또는 https://docs.astral.sh/uv
- **GPU 가 없어도 된다.** CUDA 없이 CPU로도 돌아간다(리뷰 60건에 2~3초).
  CPU만 쓸 거면 `--index-url` 없이 `uv pip install torch` 로 설치한다.
- RTX 50 시리즈(Blackwell)는 반드시 `cu128` 이상이어야 한다. 구버전은 커널이 없어 실패한다.

## 3. 서버 켜기

```bash
cd model-server
./.venv/Scripts/python.exe serve.py --model klue/roberta-small --binary --model-en distilbert-base-uncased
# 한국어만 띄우려면 --model-en 을 빼면 된다. 폴더 이름: ckpt/klue_roberta-small · ckpt/distilbert-base-uncased
```

```
모델 로드 중... klue_roberta-small (cuda)
모델 로드 중... distilbert-base-uncased (cuda)
준비 완료
http://127.0.0.1:8799
```

이 창은 **켜둔 채로** 둔다.

## 4. 브라우저에서 실행

1. 아고다 **숙소 상세 페이지**를 연다 (한국어 리뷰가 많은 곳이 좋다)
2. `F12` → `Console`
3. 아래 한 줄을 붙여넣고 Enter

```js
fetch("http://127.0.0.1:8799/panel.js").then(r=>r.text()).then(eval)
```

오른쪽에 패널이 뜨고 **아무 조작 없이** 수집·분석이 시작된다.
드래그로 옮길 수 있고, `다시` 로 재수집, `✕` 로 닫는다. 다시 열려면 `openReviewPanel()`.

> 붙여넣기가 막히면 콘솔에 `allow pasting` 을 직접 타이핑하고 Enter 한 뒤 다시 시도한다.

## 목업에 끼워 넣을 때

지금은 개발용 패널(`devpanel.ts`)이 화면을 그리지만, 목업이 준비되면 둘 중 하나로 붙인다.

```ts
// ① 그리기까지 맡긴다
import { mountReviewTab } from "review-engine";
const handle = mountReviewTab(document.querySelector("#tab-review")!);

// ② 데이터만 받아 목업 디자인대로 직접 그린다
import { createReviewController } from "review-engine";
createReviewController({ onUpdate: (insights) => myRender(insights) });
```

`onUpdate` 는 수집 단계마다 여러 번 불린다. 첫 호출이 수십 ms 안에 오고 숫자가 올라간다.
받는 데이터 형태는 `review-engine/types.ts` 의 `ReviewInsights` 에 주석과 함께 있다.

모델 층을 켜려면 analyzers 를 넘긴다(개발 패널은 이미 이렇게 하고 있다):

```ts
import { ruleAnalyzer } from "review-engine/rules";
import { modelAnalyzer } from "review-engine/modelAnalyzer";
mountReviewTab(el, { analyzers: [ruleAnalyzer, modelAnalyzer] });
```

## 동작 구조

```
브라우저 콘솔
   ↓
collect.ts      리뷰 자동 수집 ('모두 보기' 클릭 + 페이지네이션)
   ↓
analyze.ts      ruleAnalyzer   문장별 · 키워드 규칙
                modelAnalyzer  리뷰별 0/1 + 유형  ──fetch──▶ 127.0.0.1:8799
   ↓                                                          serve.py
panel.ts        화면 표시 (서로 다른 리뷰 2건 이상일 때만 노출)
```

**서버가 꺼져 있어도 화면은 뜬다.** 모델 층이 조용히 건너뛰고 규칙 결과만 보여준다.

## 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| `분석 0건 · 외국어 N건은 제외` | 그 숙소 리뷰가 외국어다. 한국 숙소로 바꾸거나 페이지에서 리뷰 언어를 한국어로 |
| 수집이 5건에서 멈춤 | `모두 보기` 버튼을 못 찾은 것. 콘솔에 `reviewDebug()` 를 치면 원인이 표로 나온다 |
| 콘솔에 `[cost-model] 서버에 연결하지 못해` | 서버가 안 켜져 있다 (3번) |
| 유형이 안 뜨고 "추가비용 언급"만 | `thresholds.json` 이 모델 폴더에 없다 |
| 붙여넣기가 안 됨 | 콘솔에 `allow pasting` 입력 후 재시도 |

## 지금 성능 (참고)

test 303건 기준. 자세한 건 [RESULTS.md](RESULTS.md).

| | F1 | 비고 |
|---|---|---|
| 추가비용 여부 | **0.859** | 언어 베이스라인 0.646 대비 +0.213 |
| 세금·숙박세 | 0.962 | 쓸 만함 |
| 보증금 | 0.800 | 쓸 만함 |
| 기타부대 · 시설이용 · 식음료 | 0.16~0.53 | **아직 약하다** |

라벨이 LLM 생성이라 이 숫자는 "LLM 라벨과의 일치"이지 정답과의 일치가 아니다.
데이터 재수집·재라벨링 후 다시 학습할 예정이며, 그때는 모델 폴더만 교체하면 된다
(브라우저 코드는 안 바뀐다).
