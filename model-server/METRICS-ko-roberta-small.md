# ko-fee-classifier v3 — 한국어 추가비용 분류기 (`klue/roberta-small`)

2026-09-23 · v2(`klue/roberta-base`)를 **같은 레시피로 small 에 재학습**해 교체. 정확도는 같고 계산은 절반.
체크포인트 `ckpt/klue_roberta-small/` (261MB, git 무시 · Docker 이미지에 포함).

## 왜 바꿨나

서버 지연의 병목이 한국어 모델이었다 (4 vCPU 기준 ko 페이지 3.4s · en 1.5s).
12층 base → 6층 small 로 요청당 계산이 절반이 되고, 같은 인스턴스로 동시 사용자를 2배 받는다.

## 학습 설정 (v2 와 동일)

| 항목 | 값 |
|---|---|
| 베이스 | `klue/roberta-small` (6층 · hidden 768 · 약 6,800만 파라미터) |
| epochs / batch / lr | 4 / 16 / 2e-5 |
| max_len · weight decay · warmup | 256 · 0.01 · 10% |
| 시드 · 분할 | 42 · `given` (제공된 train 693 / val 144 / test 145) |
| 체크포인트 선택 | val Macro F1 최고 (epoch 4: 0.794 → 0.855 → 0.866 → 0.874) |
| 학습 환경 | 맥 CPU, `train_ko_fee.py` 그대로 |

같이 시도한 6 epoch · lr 3e-5 는 test 0.844 로 더 나빠서 탈락.

## 성능 — v2 base 와 나란히

| | **v3 small** | v2 base |
|---|---|---|
| test 145 · Macro F1 / MCC | **0.860 / +0.726** | 0.860 / +0.720 |
| test 145 · TP FP FN TN | 93 · 12 · 5 · 35 | 88 · 8 · 10 · 39 |
| val 144 · Macro F1 / MCC | 0.874 / +0.747 | 0.865 / +0.739 |
| **사람 라벨 val+test 36건** (학습에 없던 행) · Macro F1 / MCC | 0.750 / +0.50 | 0.776 / +0.57 |
| 같은 36건 · 틀린 개수 FP / FN | 4 / 3 = **7** | 2 / 5 = **7** |
| 36건 중 규칙이 `negated` 로 놓친 실제 비용 3건 재현 | **3/3** | 2/3 |
| 페이지 40문장 지연 (맥 1스레드, 길이정렬 B8) | **0.61s** | 1.12s |

- 틀린 개수는 같고 종류가 다르다: base 는 미탐 쪽, small 은 과탐 쪽. 제품 기준("놓치는 게 더 나쁘다")에는 small 이 맞는 방향
- n=36 이라 F1 0.026 차이는 잡음. 정직한 결론은 "**같은 정확도, 절반 계산**"

## 주의 (v2 와 동일)

- test/val 리뷰의 95% 가 train 에 나온 숙소에서 왔다 → 145건 숫자는 상한. 그래서 36건 사람 라벨 셋을 같이 본다
- 라벨 대부분이 LLM 생성. F1 은 "LLM 라벨과의 일치"다
- 재현: `python train_ko_fee.py --model klue/roberta-small --data_dir data/ko --out_dir runs/small_a --split given --epochs 4 --bs 16 --lr 2e-5 --max_len 256 --seed 42 --save_model 1`

## 알려진 약점 (2026-09-24 실측, 재학습 때 반영할 것)

**통사적 부정을 못 읽는다.** "무료·무상" 같은 어휘 부정은 잡지만(2/2), "~요금 없이", "전혀 청구되지 않았습니다",
"포함되어 있어서 따로 낸 돈이 없습니다" 같은 통사 부정은 비용 없음 10문장 중 7건을 mention 95~98% 로 오판했다.
학습셋의 음성 예가 NEG_CUE("무료") 중심이라 그렇다. 재학습 시 **부정문 음성 샘플**을 따로 채워야 한다.
익스텐션 money-gate 로 덮지 않기로 했다(규칙으로 모델 결함을 가리면 이유가 남지 않는다). 실제 1500건에서 발생 1/27.

재학습 때 테스트 케이스로 쓸 패턴 3종 (지금 모델은 셋 다 mention 으로 오판):
```
"추가 요금 없이 … 받았습니다"          ← 실제 1500건에서 1회 발생
"추가 요금 없이 … 해주셨어요"
"… 추가 비용은 전혀 청구되지 않았습니다"
```
반대로 지금 맞추는 음성은 전부 `무료`·`무상` 어휘 단서가 있는 경우다.
