## 2. 버그 (역할 1번)

### 무엇이 문제였나 — 한 줄씩

| | 증상 | 상태 |
|---|---|---|
| **B1** | 스크롤하면 카드가 커서 밑이 아닌 이전 요금을 계속 보여줌 | **해소** (구조가 바뀌어 성립 안 함) |
| **B2** | 한번 잡힌 요금제가 절대 안 풀림 — 지도·사진으로 옮겨도 테두리가 남음 | **해결 · 실측 확인** |
| **B3** | 요금 목록 아래 빈 공간에서도 마지막 요금이 잡힘 | 코드 반영, **미검증** |
| **B4** | 같은 가격이 여러 줄이면 엉뚱한 줄이 잡힐 수 있음 | 코드 반영, **미검증** |
| **B5** | 누르지 않은 취소정책 모달이 저절로 떴다 사라짐 (반복) | **해결 · 실측 확인** |
| **B6** | 페이지 어디의 "더보기"든 전체 재분석이 즉시 돌아감 | **스킵** (실측: 의도한 버튼만 걸림) |
| **B7** | 모달 닫기가 "우리가 연 것"인지 확인 안 함 + 전역 ESC | **전역 ESC 제거** · 나머지는 보류 |

---

### 이 다섯 개를 어떻게 풀었나 — 개별 수정이 아니라 **구조 교체**

B1~B5 는 따로따로 고치다가, 결국 **공통 뿌리 하나**로 수렴했다.

> **호버가 곧 요약이었다.** 마우스를 올린 요금제로 카드가 바뀌고, 그 요금제의
> 취소조건 원문을 읽으려고 모달까지 열었다.

여기서 두 가지가 동시에 나온다 — *원하는 옵션을 멈춰서 볼 수가 없다*, 그리고
*본 적 없는 요금제는 결국 전부 모달을 열어본다*. 호버 판정을 아무리 정교하게 다듬어도
(B1~B4) 빈도만 줄 뿐 이 둘은 남는다.

그래서 **요약을 정하는 주체를 바꿨다.**

```
호버     →  파란 테두리와 ✓ 버튼만 따라다님.  카드는 안 바뀜
✓ 클릭   →  그 요금제가 선택됨. 카드 고정. 그때 한 번만 원문을 읽음
스크롤·이동 →  선택은 그대로
```

**설계의 네 기둥**

| | 내용 | 무엇을 없앴나 |
|---|---|---|
| 추측을 그만둠 | `resolveFocus` 에서 뷰포트 중앙 추정 + 히스테리시스 + 호버 덮어쓰기(3중)를 걷어냄. 고른 것만 보여주고, 안 골랐으면 안내 | **B1** 이 성립할 수 없게 됨 — 카드는 애초에 커서를 따라가지 않는다 |
| 선택을 **내용**으로 기억 | 아고다는 스크롤마다 행을 새로 그린다. 노드로 기억하면 매번 잃는다. **금액 숫자**만 뽑아 서명으로 쓰고, 그마저 바뀌면 자리로 되찾음 | **B4** 의 문제(같은 값 구분)를 선택 쪽에서 해결. **B5** 의 반복 원인도 같은 뿌리였다 |
| 호버 판정이 **가로**와 **창 이탈**을 봄 | 기존엔 세로(Y)만 봐서 가로로 움직여도 안 풀렸다. 창 밖으로 나가면 이벤트가 끊겨 표시가 굳었다 | **B2** |
| 원문은 **선택한 것만** 읽음 | 모달을 여는 총량이 "요금제 개수"에서 "사용자가 고른 2~3개"로 | **B5** 를 빈도가 아니라 총량에서 끊음 |

**곁들여 나온 것** — ✓ 버튼을 카드 우측 상단에 띄우려다 첫 요금제만 안 눌리는 문제가
나왔다. 카드 상단이 요금 박스보다 위에 있어(《예약 가능한 최저가》 띠) 판정 범위 밖이었다.
판정 범위를 카드 상단까지 넓혀 해결했다. 버튼·칩은 아고다 DOM 에 넣지 않고 띄워서
좌표만 맞춘다 — 남의 레이아웃을 밀지 않고 재렌더에도 다시 꽂을 필요가 없다.

**확장 여지** — 선택은 배열(`picks`)로 다루고 `MAX_PICKS = 1` 로만 제한했다.
다른 팀원의 "숙소 담아두기"와 붙일 때 그 숫자만 올리면 된다.

### 남은 작업

#### B6 · 페이지 어디의 "더보기"든 전체 재분석 — **스킵하기로 결정**

실측 결과 지금 화면에서 정규식에 걸리는 건 `요금 N개 더 보기` **하나뿐**이고,
그건 원래 잡으려던 버튼이 맞다. "리뷰·편의시설 더보기까지 걸린다"는 건 코드만 보고 한
추측이었고 확인되지 않았다.

선택 모델로 바뀌면서 재스캔이 카드 내용을 바꾸지도 않는다 — 남은 건 순수한 성능 비용뿐.
**버그가 아니라 위생 항목으로 내린다.**

#### B7 · 모달 닫기 — **전역 ESC만 제거, 나머지는 보류**

닫기 버튼을 못 찾을 때 `document` 전체에 Escape 를 쏘던 폴백을 걷어냈다. 근거 두 가지:

1. 아고다 취소정책 모달은 **Escape 로 닫히지 않는다** (직접 눌러 확인)
2. 그런데도 모달은 저절로 닫히고 있다 → **X 버튼이 늘 찾아지고 있고 이 폴백은 한 번도
   불리지 않았다.** 불렸어도 닫지 못했을 것이다

효과 없이 화면 전체에 Escape 를 뿌리는 위험만 남으므로 삭제했다.

남은 것 — "우리가 연 모달인지 확인하지 않고 첫 번째 모달을 닫는다". 자동 펼치기는
시작할 때 이미 모달이 열려 있으면 아예 시작하지 않으므로, 겹치려면 우리 0.4~2초 창
**안에서** 사용자가 우리 모달을 닫고 다른 걸 열어야 한다. **실질 위험이 낮아 보류.**

## 5. 팀원 충돌 주의

`extension/` 의 커밋은 **전부 윤서**가 했다.
역할 **4번 "타 OTA 확장(트립닷컴·부킹닷컴)"도 윤서 담당**인데,
그 작업은 `content.js` 사이트 매칭과 `briefing.js` 화면 읽기를 건드린다 — **같은 파일이다.**

- [ ] 윤서에게 공유: "`briefing.js` 호버 처리부 + `content.js` 스캔 트리거를 건드린다"
- [ ] `main` 직접 작업 금지 → `윤상/ui-debug`
- [ ] `reviewtab.js` 는 빌드 결과물 — 직접 고치지 않는다
