ClearBooking : 호텔 실결제액·취소 위약금 개인정보처리방침

시행일자: 2026-09-24 (최초 게시 2026-09-16)

"ClearBooking : 호텔 실결제액·취소 위약금"(이하 "확장 프로그램")은 아고다(agoda.com)·트립닷컴(trip.com)·부킹닷컴(booking.com) 숙소 예약 페이지에서 세금·수수료를 포함한 실제 결제 총액과 취소 시 예상 손실액을 한 장의 브리핑 카드로 보여주고, 공개된 리뷰에서 숨은 비용(도시세·숙박세, 보증금, 조식, 시설이용료, 현장결제 등) 언급을 찾아 보여주는 브라우저 확장 프로그램입니다. 이 방침은 확장 프로그램이 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 수집·처리하는 정보

구분내용처리 방식
가격 정보 현재 보고 있는 예약 페이지에 표시된 요금·세금·수수료 항목 브라우저 내에서만 읽어 실제 총액을 계산 · 외부로 전송되지 않음
취소정책 원문 페이지에 표시된 취소·환불 조건 텍스트 브라우저 내에서만 읽어 예상 손실액을 계산 · 외부로 전송되지 않음
공개 리뷰 텍스트 해당 숙소에 대해 예약 사이트(아고다·트립닷컴·부킹닷컴)에 공개적으로 게시된 이용자 리뷰 중, 비용 관련 키워드가 든 문장 숨은 비용 언급 여부를 분류하기 위해 자사 분류 서버로 전송 (아래 상자 참고). 리뷰는 확장 프로그램이 해당 예약 사이트 자체의 리뷰 API를 호출해 불러옵니다. 아고다의 경우 이때 브라우저가 아고다에 접속할 때 쓰는 로그인 상태(쿠키)가 그대로 아고다 서버로 함께 전송되며, 트립닷컴·부킹닷컴 리뷰 요청은 로그인 상태 없이 보냅니다. 이는 예약 사이트 자체 서버로 가는 요청이며, 확장 프로그램은 로그인 정보를 읽거나 저장하지 않고 개발팀 서버로도 보내지 않습니다. 별도의 개인 식별 정보를 추가로 요청하지 않습니다.
캘린더 일정
(사용자가 버튼을 누를 때만)		 브리핑 카드가 보여주는 무료취소 마감일, 숙소명, 체크인 날짜·박수, 예약 금액, 예약 페이지 주소 "다른 캘린더 (.ics)"는 브라우저 안에서 일정 파일을 만들어 사용자의 컴퓨터에 저장하며 외부로 전송되지 않습니다. "Google 캘린더"는 사용자가 버튼을 눌렀을 때에 한해 구글 캘린더 페이지가 새 탭으로 열리고, 이때 위 내용이 그 주소에 담겨 Google로 전달됩니다(Google의 개인정보처리방침이 적용됩니다). 버튼을 누르지 않으면 아무것도 전달되지 않으며, 개발팀 서버로는 어느 경우에도 전송되지 않습니다.
리뷰 텍스트를 자사 서버로 전송해 분류합니다.
숨은 비용 언급을 찾아내는 기능은 자체 학습한 분류 모델을 사용하며, 이 모델은 확장 프로그램이 아닌 별도 서버에서 동작합니다. 이 기능을 위해 리뷰 전문이 아니라 비용 관련 키워드(조식·주차·보증금·세금 등)가 든 문장만 발췌해(한 번의 요청당 최대 100문장, 문장 한 건당 최대 2,000자) 그 문장의 언어 코드(한국어/영어)와 함께 해당 서버로 전송하며, 분류 결과만 돌려받습니다. 리뷰 분석을 시작하기 전에 서버가 대기 상태에서 깨어나도록 상태 확인 요청을 한 번 보내는데, 이 요청에는 아무 데이터도 담기지 않습니다. 서버는 전송된 문장을 저장하지 않고 요청 처리 후 즉시 폐기합니다. 발췌 문장에는 작성자 본인 또는 제3자(예: 숙소 직원)의 이름 등 개인정보가 포함되어 있을 수 있으며, 이 경우에도 동일하게 전송 후 즉시 폐기되고 별도로 저장되지 않습니다. 이 서버에 연결할 수 없는 경우에도 확장 프로그램의 나머지 기능(가격·취소조건 브리핑, 규칙 기반 리뷰 표시)은 정상 동작합니다.

언제 전송되나요? 아고다·트립닷컴·부킹닷컴 숙소 상세 페이지에서 가격·취소조건이 화면에 표시되는 시점에 자동으로 시작되며, 사용자가 사이트의 리뷰 탭을 직접 열지 않아도 실행됩니다. 숙소 한 곳당 한 번만 수행되고, 검색 결과 목록 화면에서는 동작하지 않습니다.

2. 수집하지 않는 정보

  • 로그인·계정 정보 — 확장 프로그램 자체는 회원가입·로그인 기능이 없으며, 아이디·비밀번호를 요청하거나 저장하지 않습니다. 다만 아고다의 리뷰를 불러오는 요청에는 브라우저에 이미 저장된 아고다 로그인 상태가 함께 실려 아고다 서버로 전송되며(위 1번 참고), 확장 프로그램이 그 내용을 읽거나 개발팀 서버로 보내지는 않습니다.
  • 결제·금융 정보 — 카드번호, 계좌번호 등 결제 수단 정보를 수집하지 않습니다. 화면에 표시된 "총액"은 어디까지나 참고용 계산 결과입니다.
  • 이름·연락처 등 개인 식별 정보 — 확장 프로그램은 이러한 정보를 별도로 요청하지 않습니다.

3. 정보의 저장 위치와 보관 기간

  • 가격·취소조건 계산 결과, 브리핑 카드의 화면 위치 등 사용성 관련 값은 chrome.storage.local을 통해 사용자의 브라우저에만 저장됩니다. 별도 계정이나 클라우드로 동기화되지 않으며, 개발팀 서버로도 전송되지 않습니다.
  • "숙소 저장" 기능으로 사용자가 직접 저장한 숙소 목록(숙소 이름, 예약 사이트, 페이지 주소, 체크인 날짜와 박수, 계산된 총액, 취소 조건 요약, 브리핑 결과 요약, 저장 시각)도 같은 방식으로 사용자의 브라우저에만 저장되며, 툴바 팝업에서 사용자가 직접 삭제할 수 있습니다. 개발팀 서버로 전송되지 않습니다.
  • 리뷰 분류 서버는 Google Cloud Platform(Cloud Run)의 대한민국 서울 리전에서 운영되며, 주소는 https://clear-booking-cost-api-12016686349.asia-northeast3.run.app 입니다. 리뷰 텍스트가 국외로 이전되지 않습니다.
  • 리뷰 분류를 위해 서버로 전송된 텍스트는 응답을 생성하는 즉시 폐기되며, 데이터베이스 등에 별도 저장하지 않습니다.
  • 서버 운영 과정에서 접속 IP·시각 등 기본 접속 기록이 클라우드 제공자(Google Cloud Run)에 의해 일시적으로 기록될 수 있습니다. 개발팀은 이 기록을 별도로 수집하거나 분석하지 않습니다.

4. 제3자 제공

수집한 정보를 위 1번의 분류 처리 목적 외에 제3자에게 제공하거나 판매하지 않습니다. 다만 사용자가 "Google 캘린더" 버튼을 직접 눌렀을 때에 한해, 그 일정의 내용(위 1번 참고)이 Google로 전달됩니다. 확장 프로그램의 핵심 기능과 무관한 목적(광고, 신용평가 등)으로 사용하지 않습니다.
