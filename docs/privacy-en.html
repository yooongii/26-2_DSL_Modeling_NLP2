ClearBooking : 호텔 실결제액·취소 위약금 — Privacy Policy

Effective date: 2026-09-24 (first published 2026-09-16)

"ClearBooking : 호텔 실결제액·취소 위약금" (the "Extension") is a browser extension that, on Agoda (agoda.com), Trip.com (trip.com) and Booking.com (booking.com) accommodation booking pages, shows the real total payable including taxes and fees and the estimated loss if you cancel, in a single briefing card. It also scans publicly posted reviews for mentions of hidden costs (city/accommodation tax, deposits, breakfast, facility fees, on-site payments, and similar). This policy explains what information the Extension handles and how.

1. Information collected and processed

TypeContentHow it is handled
Price information Rate, tax and fee items displayed on the booking page you are currently viewing Read within the browser only, to compute the real total · never sent anywhere
Cancellation policy text Cancellation and refund terms shown on the page Read within the browser only, to compute the estimated loss · never sent anywhere
Public review text From user reviews publicly posted on the booking site (Agoda, Trip.com or Booking.com) for the property in question, only the sentences that contain cost-related keywords Sent to our classification server to determine whether hidden costs are mentioned (see the note below). Reviews are retrieved by the Extension calling the booking site's own review API. For Agoda, that request carries your existing login state (cookies) for Agoda to Agoda's own servers; Trip.com and Booking.com review requests are sent without any login state. The request goes to the booking site itself, and the Extension neither reads nor stores that login state, nor sends it to the development team's servers. No additional personally identifying information is requested.
Calendar event
(only when you press the button)		 The free-cancellation deadline shown on the briefing card, the property name, check-in date and number of nights, the total price, and the booking page address "Other calendars (.ics)" builds an event file in the browser and saves it to your computer; nothing is sent anywhere. "Google Calendar" opens Google Calendar in a new tab only when you press it, and at that moment the content above is carried in the address and passed to Google (Google's privacy policy applies). If you do not press the button, nothing is passed on, and in no case is it sent to the development team's servers.
Review text is sent to our own server for classification.
The hidden-cost detection feature uses a classification model we trained ourselves, and that model runs on a separate server rather than inside the Extension. For this feature, the Extension does not send full reviews: it sends only the sentences that contain a cost-related keyword (breakfast, parking, deposit, tax and similar) — at most 100 sentences per request and at most 2,000 characters per sentence — together with the language code of the sentence (Korean/English); only the classification result is returned. Before review analysis starts, the Extension sends one status-check request so the server can wake from idle; that request carries no data. The server does not store the text it receives and discards it immediately after handling the request. Such sentences may contain personal information such as the name of the author or of a third party (for example, hotel staff); in that case it is likewise discarded immediately after transmission and is not stored separately. If the server cannot be reached, the rest of the Extension (price and cancellation briefing, rule-based review display) continues to work normally.

When does this happen? It starts automatically at the moment price and cancellation terms are displayed on an Agoda, Trip.com or Booking.com property detail page — you do not have to open the site's review tab yourself. It runs once per property, and does not run on search result listing pages.

2. Information not collected

  • Login or account information — The Extension itself has no sign-up or login feature, and does not request or store usernames or passwords. Note that the request used to fetch reviews from Agoda does carry your existing Agoda login state to Agoda's own servers (see section 1); the Extension does not read it or send it to the development team's servers.
  • Payment or financial information — No card numbers, account numbers or other payment credentials are collected. The "total" shown on screen is a computed figure for reference only.
  • Names, contact details and other identifying information — The Extension does not separately request any such information.

3. Where information is stored, and for how long

  • Usability values such as computed price and cancellation results and the on-screen position of the briefing card are stored only in the user's browser via chrome.storage.local. They are not synced to any account or cloud service, and are not transmitted to the development team's servers.
  • The list of properties you save with the "save this stay" feature (property name, booking site, page URL, check-in date and number of nights, computed total, cancellation summary, briefing summary, time saved) is stored the same way, only in your browser, and you can delete entries yourself from the toolbar popup. It is not transmitted to the development team's servers.
  • The review classification server runs on Google Cloud Platform (Cloud Run) in the Seoul, Republic of Korea region, at https://clear-booking-cost-api-12016686349.asia-northeast3.run.app. Review text is not transferred outside that region.
  • Text sent to the server for review classification is discarded as soon as the response is generated, and is not stored in a database or anywhere else.
  • In the course of operating the server, basic access records such as client IP address and timestamp may be logged temporarily by the cloud provider (Google Cloud Run). The development team does not separately collect or analyze these records.

4. Disclosure to third parties

We do not provide or sell collected information to third parties for any purpose other than the classification processing described in section 1. The one exception is when you yourself press the "Google Calendar" button, in which case the content of that event (see section 1) is passed to Google. We do not use it for purposes unrelated to the Extension's core functionality, such as advertising or credit scoring.

The Extension maintains no user accounts, so there is no personal account information held on file. If you nonetheless have questions about how data is handled, or wish to request deletion or correction, please contact us at the address below.
