ClearBooking은 Agoda·Trip.com·Booking.com과 제휴·승인·후원 관계가 없는 비공식 확장 프로그램입니다.

ClearBooking은 이 정보를 한 장의 "예약 브리핑" 카드로 정리해 예약 전 판단을

실제 결제 총액: 표시 가격과 세금·수수료를 포함한 총액을 비교해 실제 결제금액을

취소 리스크: 취소정책 원문을 분석해 위약금이 시작되는 시점과 취소 시 예상 손실액을

숙소 저장: 비교하고 싶은 숙소를 카드에서 저장해 두고 툴바 팝업에서 한눈에 봅니다.
